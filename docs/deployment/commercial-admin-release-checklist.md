## 权限

- `SUPER_ADMIN` 可访问 `/api/admin/*`。
- `SCHOOL_ADMIN`、`TEACHER`、`PARENT` 访问 `/api/admin/*` 返回 403。
- 校方、教师、家长不能跨学校读取数据。
- 模拟校方视角必须生成短期 token 并写审计。

## 安全

- JWT 密钥来自环境变量。
- 管理后台不展示默认账号密码。
- 密码使用 BCrypt。
- Markdown 发布前做 XSS 清洗。
- 上传文件限制类型和大小。
- 导出、删除、禁用、重置密码、发布内容全部写审计。
