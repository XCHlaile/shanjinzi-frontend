# 备份恢复 Runbook

## 备份内容

- MySQL：业务表、Flyway schema history、审计日志。
- 对象存储：Markdown 图片、资讯封面、动态媒体文件。
- 配置：生产环境变量、Nginx 路由、部署版本号。

## 备份频率

- MySQL 每日全量备份，每小时增量备份。
- 对象存储开启版本化。
- 发布前手动创建一次全量备份。

## 恢复演练

1. 新建临时 MySQL 实例。
2. 从最近全量和增量备份恢复。
3. 启动后端指向临时库。
4. 校验登录、用户列表、学校列表、消息列表、页面读取、资讯读取。
5. 抽样验证审计 hash chain 未断裂。

## 失败处理

- 数据库恢复失败：停止发布，保留旧系统。
- 对象存储恢复失败：页面内容可先上线，媒体文件使用旧 URL 兜底。
- 审计校验失败：禁止上线，保留恢复现场。
